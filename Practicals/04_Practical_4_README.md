# Practical 4 — pgvector and OpenAPI

## Requirements
- PostgreSQL
- pgvector extension
- Swagger Editor or another OpenAPI editor

## PostgreSQL part
1. Connect to `bookflow_db`.
2. Open `04_Practical_4_pgvector.sql`.
3. Execute it.

## OpenAPI part
Open `04_Practical_4_OpenAPI.yaml` in Swagger Editor. It defines the required search endpoint, query parameters, success response, and 400 error response.
