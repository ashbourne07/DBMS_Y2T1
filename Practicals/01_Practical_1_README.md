# Practical 1 — Database Setup

## Requirements
- PostgreSQL
- pgAdmin or psql

## Run
1. Open PostgreSQL/pgAdmin.
2. Open `01_Practical_1.sql`.
3. Run the file.
4. If using pgAdmin, connect to `bookflow_db` after the `CREATE DATABASE` command and run the remaining statements there.

The script creates `Books` and `Members` and inserts the required sample records.
