# Practical 2 — Dashboard

## Requirements
- PostgreSQL
- `bookflow_db` from Practical 1

## Run
1. Connect to `bookflow_db`.
2. Open `02_Practical_2.sql` in pgAdmin Query Tool or psql.
3. Execute the complete file.

It creates `Loans` and `Donation_History`, demonstrates JOIN/GROUP BY, performs the donation transaction, and creates the ISBN index.
