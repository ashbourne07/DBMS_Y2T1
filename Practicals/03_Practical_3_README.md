# Practical 3 — MongoDB

## Requirements
- MongoDB Server
- `mongosh`

## Run
1. Start MongoDB.
2. Open PowerShell/Terminal in this folder.
3. Run:

```bash
mongosh 03_Practical_3.js
```

The script creates/uses `bookflow_db.book_metadata`, inserts the sample documents, runs comparison/regex queries, the aggregation pipeline, and creates the text index.
